# Banking-System

 Bank System (Python Project):
 About the Project:
This is a simple bank system created using Python.
It allows a user to log in and perform basic banking operations.
 Login System:
User must enter correct username and password
If login is correct → access is given
If wrong → shows error message
 Features:
Check Balance:
Shows the current account balance
Deposit Money:
User can add money to the account
Balance will increase
Withdraw Money:
User can withdraw money
If balance is low → shows "No balance"
Transaction History:
Shows all deposits and withdrawals
Exit
Closes the program
Initial Details:
Default username: jasla
Default password: 4321
Starting balance: 1000
 Technologies Used:
Python (basic concepts like loops, conditions, list)
 conclusion:
This project helps to understand basic Python concepts and how a simple banking system works
